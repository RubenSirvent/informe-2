# Informe 2 - Pruebas Unitarias

## Descripción

Este proyecto corresponde al desarrollo del Informe 2, utilizando Maven para la gestión del proyecto y JUnit para la implementación de pruebas unitarias.

El proyecto contiene operaciones básicas de multiplicación y división, cada una acompañada de su respectiva prueba unitaria.

## Tecnologías utilizadas

- Java
- Maven
- JUnit 4.13.2
- Git
